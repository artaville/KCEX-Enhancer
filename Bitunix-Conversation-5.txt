## ۲. کشف مهم درباره شناسه پوزیشن

آبجکت پوزیشن این فیلد را دارد:

```javascript
position.id
```

اما این فیلد را ندارد:

```javascript
position.positionId
```

این موضوع برای ما مهم است، چون متدهای رسمی Broker که قبلاً پیدا کردیم، شناسه را به‌صورت آرگومان اول دریافت می‌کنند:

```javascript
adapter.closePosition(position.id)
adapter.reversePosition(position.id)
```

بنابراین برای مسیر مستقیم Adapter نیازی به ساختن `positionId` نداریم.

              chunkName,
              moduleId: String(moduleId),
              sourceLength: src.length,
              groups: hits.map(h => h.group),
              excerpts: hits.slice(0, MAX.excerpts)
            });

            totalModuleRecords++;

            if (totalModuleRecords >= MAX.modules) break;
          }

          if (totalModuleRecords >= MAX.modules || scanned >= 10000) break;

        if (totalModuleRecords >= MAX.modules || scanned >= 10000) break;
